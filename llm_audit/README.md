# LLM-Assisted Consistency Audit Materials

This directory contains the supplementary 200-command LLM-assisted consistency audit.

- `subset_200/` contains the blind/gold audit subset and prompt material.
- `raw_model_outputs/` contains the retained hosted-model outputs.
- `results/` contains strict and normalized comparisons and summary files.

ChatGPT and Gemini are the main audit sources reported in the accompanying manuscript. DeepSeek outputs are retained as preliminary material for transparency, but schema-compliance issues prevented that run from being treated as part of the main audit evidence.

These outputs are not human inter-annotator agreement and are not treated as an independent gold standard.
