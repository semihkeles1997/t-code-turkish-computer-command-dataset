# Results

This directory contains retained evaluation outputs associated with the T-Code v4 manuscript.

## Final benchmark outputs

- `berturk_final_2700/` — BERTurk results on the final internal test and challenge evaluations
- `transformer_baselines/` — mBERT and XLM-RoBERTa-base results
- `bilstm_crf/` — BiLSTM-CRF results

## Development and audit outputs

- `challenge_initial/` — development-stage challenge analysis used before the final 200-record augmentation
- `berturk_challenge_gold/` — retained challenge-evaluation outputs from the development process
- `inter_annotator_agreement.json` — final human agreement summary

The ZIP files in this directory are archive bundles of retained result outputs. They are provided for convenience; the corresponding extracted result directories remain the canonical readable form where both are present.

Obsolete 67-label development metrics are not part of the final T-Code v4 benchmark release.
